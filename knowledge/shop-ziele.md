# Ziele im Shop und auf dieser Website

Der Shop läuft auf Shopify. Links dorthin beginnen immer mit dem Platzhalter {{facts.shopUrl}},
nie mit einer ausgeschriebenen Adresse. Kategorien sind stabil, Produktadressen (/products/…)
ändern sich; deshalb wird auf Kategorien verlinkt.
